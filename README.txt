leven Academy
=================================

طريقة التشغيل:
1) افتح ملف index.html في المتصفح (موقع الأكاديمية الوحيد — لا يوجد أي نادٍ آخر)
2) المدير يدخل من نفس زر "دخول / حساب" الموجود في الموقع، كأنه عضو عادي تماماً

بيانات المدير السرية (كما طلبت):
- البريد: eleven.admin@ec.11
- كلمة المرور: admin.eleven@11

كيف يعمل الدخول الخفي؟
- لا يوجد أي زر أو رابط يكشف الإدارة في الموقع
- المدير يضع بريده وكلمة مروره في نافذة الدخول العادية
- يظهر اسمه كأي عضو: "مرحباً، الإدارة" مع زر ⚙️ صغير فقط يراه هو
- عند دخوله تظهر له أزرار حذف خفية (🗑) على الأخبار والمباريات واللاعبين
- لوحة التحكم الكاملة في admin.html — محمية بنفس البيانات السرية

ما تستطيع الإدارة فعله (كل البيانات تضاف يدوياً — لا شيء وهمي):
- تغيير شعار الموقع من داخل لوحة التحكم
- نشر الأخبار مع رفع الصور
- إضافة المباريات: المنافس + صورته + التاريخ + الملعب + الحالة + النتيجة
- بناء تشكيلة كل مباراة: اسم ورقم ومركز وصورة لكل لاعب
- إضافة لاعبي الأكاديمية مع صورهم وأرقامهم
- العدّ التنازلي للمباريات القادمة يظهر تلقائياً

ملاحظات:
- البيانات تُحفظ في متصفحك (localStorage) — لا توجد أي بيانات وهمية مسبقة
- لا ترفع صوراً ضخمة جداً لأنها تُخزن في المتصفح
